# HSBC 每日庫存損益報表 — 使用說明

每天自動抓美股收盤價，算出庫存市值與損益，產生一份與原本 Excel 報表一樣的 PDF。

**不需要安裝 Microsoft Excel，也不需要 LibreOffice。**

---

## 第一次使用

1. 從開始功能表或桌面捷徑開啟「HSBC 每日庫存損益報表」。
2. 第一次開啟會自動切到「設定」頁，請選擇你的資料來源 Excel 檔，按「儲存設定」。
3. 回到「主畫面」，按 **立即產生報表**。

PDF 會存到 Excel 檔旁邊的 `PDF` 資料夾（可以在「設定」頁改成別的位置），
檔名是 `HSBC List_YYYYMMDD.pdf`，日期用的是美股實際收盤日。

---

## 四個頁面

### 主畫面
- **立即產生報表**：馬上抓一次最新收盤價並產生 PDF
- 跑完會列出每檔股票的收盤價、單位數、市值、損益（賺綠色、賠紅色），
  下方顯示庫存損益小計與已實現損益小計
- **開啟最新報表** / **開啟 PDF 資料夾**

### 自動排程
- 設定每天幾點自動執行，按「啟用／更新排程」
- 背景執行，**不需要保持登入**，也不會跳出視窗
- 電腦必須開著。已設定睡眠喚醒，但**完全關機時無法喚醒**
- 若錯過執行時間，下次開機後會盡快補跑一次

### 設定
- **資料來源 Excel**：你平常維護買賣明細的那個檔案
- **PDF 輸出資料夾**：留空則存到 Excel 檔旁邊的 `PDF` 子資料夾
- **中文字型**：留空則自動尋找細明體／微軟正黑體／標楷體

### 執行紀錄
- 顯示每次執行的詳細訊息。log 檔也會存在
  `%LOCALAPPDATA%\HSBC Daily Report\logs\`，30 天前的會自動清掉

---

## 重要：你的 Excel 檔不會被修改

程式**全程唯讀**讀取那個 xlsx，不會寫入、不會改動、不會覆蓋。
你買賣股票時照舊用 Excel 編輯那個檔案就好。

程式會自動偵測目前持股 —— HSBC 工作表 H 欄是 `=工作表1!Bn` 公式的那幾列就是持股列。
**所以你在 Excel 裡新增或移除持股，程式會自動跟著變，不需要改任何設定。**

### 一個前提
程式讀的是「Excel 上次算好並存檔的結果」。你用 Excel 編輯完**存檔**後就是最新的，
正常使用不會有問題。如果看到「單位數或申贖成本不是數字」的錯誤，
用 Excel 開啟那個檔案、存一次檔再跑即可。

## 常見問題

**Q：報表上的中文變成空白？**
A：找不到中文字型。到「設定」頁指定一個 `.ttf` / `.ttc` 中文字型檔
（例如 `C:\Windows\Fonts\mingliu.ttc`）。

**Q：排程時間到了卻沒有產生報表？**
A：先確認電腦當時是開機狀態（完全關機無法喚醒）。再到「執行紀錄」頁或
`%LOCALAPPDATA%\HSBC Daily Report\logs\` 看看那次執行的錯誤訊息。

**Q：PDF 沒有產生，說檔案被佔用？**
A：同名的 PDF 正開在 PDF 閱讀器裡，關掉後重跑即可。

**Q：假日或休市日跑會怎樣？**
A：程式抓的是「所有持股都有收盤價的最新共同交易日」，休市日跑只會重新產生
同一個交易日的報表，不會出錯。

---

## 解除安裝

「設定 → 應用程式」或開始功能表的「解除安裝」，會一併移除每日排程。
你的 Excel 檔與已產生的 PDF 都不會被刪除。
